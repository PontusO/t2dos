# cc -O 3c: lea (frame-address) conversion without r7 - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. (Subagent dispatch is disabled in this session by harness constraints: single model instance drives the board.)

**Goal:** Let `-O` convert functions whose only r7 use is `subw/addw rD, r7, #N` frame-address arithmetic, completing the fp-free series for every function except argv windows, pending result saves, float slots and over-window shapes.

**Architecture:** `sprel()`'s two walks (prescan + conversion) gain one arm at the `k == -1` bail: the lea line maps through the existing uniform formula at its own live depth d and rewrites to `addw rD, sp, #o`. Nothing else changes: the rewritten line loses its r7 token, so `fl_r7`, `frameless`, `trimframe` accept it as-is.

**Tech Stack:** C (`compiler/cc.c`), Python checkers in `tools/`, witness C in `tests/opt/`, qemu `host_linux` harness, GNU `arm-none-eabi` oracle.

**Spec:** `docs/superpowers/specs/2026-11-21-cc-lea-design.md`

## Global Constraints

- Without `-O` output stays byte-identical: `python3 tools/check_ref.py` ends `different: 0` after every commit.
- `compiler/cc.c` stays inside the committed cc's bootstrap subset: before committing, compile the changed file with `build/ref/cc` (`make ref` once) - it must build.
- Relative addressing only: never emit an absolute address in the rewrite.
- No em dashes in code comments or commit messages.
- TDD: pin flips go red before the implementation goes in.
- Board runs (`--selfhost`, `--board`) are pre-approved for this plan (same blanket go-ahead as 3b-iii), one port at a time; never touch the user's `screen`.
- Gotchas: `make clean` deletes `./host_linux` and plain `make` does not rebuild it (`make host` before any `--pc` check after a clean); cc binaries must run from `compiler/` (argv[0]-relative `build/host/as`); host_linux `.bin` paths must live under `root/`; greps for assembler tabs need real tabs (`printf 'add\tsp, #24'`).

## Review Focus

- **Window edges.** A descriptor cell at the frame bottom maps to `o == 0`, and `big`'s cell sits at `o == 1004`: an off-by-one in `o` names a wrong word that usually still runs until it doesn't. Pinned by `frame.bin` printing its exact numbers (Task 1) and `check_sh --pc` (Task 1).
- **Lea at live depth > 0.** A descriptor init between an arg push and a `bl` maps with that line's `d`; wrong `d` corrupts only in call-heavy code. Exercised by sh's `dollar`/`glob_word` through `check_sh --pc` (Task 1) and the board bench/basic runs (Task 3).
- **Non-goal classes must NOT convert** (converting them is silent corruption): `vstr`/`vldr` float slots, pending result saves, builtin argv windows, `sz > 4095`. Pinned by `stublea`/`rec`/`csys`/`huge` staying framed (Task 1).
- **Drain exactly once.** `trimframe` copies pops toward early returns; a copied pop next to the drain, or a missed drain, corrupts the caller. Pinned by `frame.bin`'s run (all returns execute) and the multi-return witnesses (Task 1).
- **`-O` only.** The arm lives in the `optim` path; plain builds unchanged (Task 1: `check_ref`).

**Interfaces:**

- Produces: converted lines with the exact text `addw\trD, sp, #o`, `o = k + sz + d - 4` with `k = -N` for `subw`, `k = +N` for `addw` (line `mnem\trD, r7, #N`). `fl_r7`/`frameless`/`trimframe` are untouched and must accept these lines because they contain no r7 token.

- [ ] **Step 1: Flip the frame pins (red)**

In `tools/check_frame.py`, replace the "small and big keep their frames" block with pins that a reserved-frame lea function converts: `small` and `big` contain no line with `r7` at all and end with the drain lines `add\tsp, #24` / `add\tsp, #1008` (text; `as` picks the wide encoding for 1008). Apply the same "no r7 + drain" test to `bigprom` and `amem`. `huge` keeps its existing framed pin. Do not guess `fpint`: run the checker once, read the FAIL line, and pin whatever the actual output shows (float `vpush`/`vstr` shapes keep it framed unless peep already killed the float slot) with a one-line comment naming the reason. Keep the `frame.bin` run pin `1 18 7 5 3 11 14 0 94 29 18 7` unchanged - identical behavior is part of the contract.

- [ ] **Step 2: Run it to confirm red**

Run: `make 2>&1 | tail -1 && python3 tools/check_frame.py`
Expected: FAIL on `small` (keeps r7).

- [ ] **Step 3: Implement the prescan arm**

At the prescan's `if (k == -1) return 0;` (inside `if (r7ref(i) == 1)`): before bailing, test the line text for `subw\t` / `addw\t` with base operand exactly `", r7, #"`; parse the immediate `N` (digits only). Compute `k = (subw ? -N : N)`, then `o = k + sz + d - 4`. `o < 0 || o > 1020` → `return 0` (the existing window bail). Otherwise `nconv = nconv + 1` and continue the walk (a lea line moves nothing: `d` unchanged). Non-matching `-1` forms (vstr, bare-register r7) keep bailing. A helper next to `sprewrite` sharing its `", r7, #"` scan is fine; `cc.c` must stay buildable by `build/ref/cc`.

- [ ] **Step 4: Implement the conversion-walk arm**

In the conversion walk's matching position (the `r7ref(i) == 1 && split(i) >= -1` block, same predicate as Step 3): `pset(i)`, emit `addw\trD, sp, #` + `dec(o)` (same `o`), `lend()`, `nconv + 1`. Same `o` formula - single source: reuse the Step 3 helper.

- [ ] **Step 5: Green the pins**

Run: `make 2>&1 | grep -c error; python3 tools/check_frame.py && python3 tools/check_prolog.py`
Expected: `ok: frame`, `ok: prolog`.

- [ ] **Step 6: Full PC gate**
