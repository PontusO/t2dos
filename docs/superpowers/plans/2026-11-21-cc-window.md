# cc -O 3d: argv window conversion - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. (Subagent dispatch is disabled in this session by harness constraints: single model instance drives the board.)

**Goal:** Convert the last big frame-keeping class - the builtin syscall trampoline's argv window - so the ~221 framed userland functions (sh 33, every net tool, every bench `main`) go fp-free.

**Architecture:** `sprel`'s prescan already skips each window span net-zero (`sp_syscall_save` recognizes the whole `mov r2, sp` ... `pop {r4}` sequence). The only bail left is `fl_frame`'s excuse, which matches the window's FIRST line only. Record the skipped spans in a small per-function table and let `fl_frame` excuse any line inside one.

**Tech Stack:** C (`compiler/cc.c`), Python checkers in `tools/`, witness C in `tests/opt/`, hand-written `.s` stub assembled with `build/host/as`, qemu `host_linux`, GNU `arm-none-eabi` oracle.

**Spec:** `docs/superpowers/specs/2026-11-21-cc-argv-window-design.md`

## Global Constraints

- Without `-O` output stays byte-identical: `python3 tools/check_ref.py` ends `different: 0` after every commit.
- `compiler/cc.c` stays inside the committed cc's bootstrap subset: build the changed file with `build/ref/cc -I . -o /tmp/cc_refbuilt compiler/cc.c` before committing.
- Relative addressing only; no absolute addresses in the rewrite path (none is added this round).
- No em dashes in code comments or commit messages.
- TDD: pin flips go red before the implementation goes in.
- Board runs (`--selfhost`, `bench --board`, `check_basic --board`) are pre-approved (same blanket go-ahead as 3b-iii/3c), one port at a time; merge/push NOT pre-approved.
- Gotchas: `make clean` deletes `./host_linux` (run `make host` before any `--pc` check after a clean); cc binaries resolve `as` from their own directory (run the compiler as `./compiler/cc` from the repo root); `cc` supports exactly ONE `-I`; grep for assembler tabs needs `$(printf '\t')`.

## Review Focus

- **Slot reads between the argv pushes and `blx r8`** (live depth d > 0 inside the window's push region): the mapped offset must use the line's own d. Exercised by sh's `dollar`/`glob_word` through `check_sh --pc` and by the board runs.
- **A window whose `add sp, #4n` cleanup peep moved past a result save:** `fl_resultsave`'s pv test must still claim the words. Exercised by `cret`/`csys` shapes in `check_prolog` runs.
- **An early return that crosses a window, or a second exit after one:** `na || ps || d` must read 0 at every exit pop or the function keeps its frame (no half-drained exit). Exercised by `check_sh --pc` (sh's `run_cmd`) and the prolog/frame run pins.
- **A stray unbalanced `push {r4}`** (not the trampoline's): stays bailed by the depth model, never excused by the span table (the table records only prescan-skipped spans). Pinned by `csc`/`cmixed` keeping their converted-but-saved shapes in `check_prolog`.
- **`sz == 0` window functions** (`csys`): the trio is emitted at sz 0 and removed by the conversion; the exit is a plain `pop {pc}` with no drain. Pinned by the new `csys` pin.
