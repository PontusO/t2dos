# Round B: file mtimes, `ls` timestamps, BASIC `DATE$`/`TIME$` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Files the board writes carry real UTC modification times; `ls` lists them in local time with per-file DST correctness; `basic` exposes `DATE$`/`TIME$`.

**Architecture:** The kernel registers a minute-truncated UTC callback with SDFS (storage truth stays UTC); `dirent_t` gains an `mtime` fed by `Dir::fileTime()`; a new `SYS_tzlocal = 108` exposes the tz engine's per-instant conversion (`tz_now`) so userland renders each file's own DST side; userland (`ls`, `basic`) only formats.

**Tech Stack:** C (kernel pieces in the Arduino sketch `src/kernel/kernel.ino`), userland/toolchain C inside the committed cc's subset, Python checkers under `tools/`.

**Spec:** `docs/superpowers/specs/2026-11-22-mtime-roundb-design.md` (binding; its builder-check rulings — minute truncation, `{ls,rcp,sh,basic}` re-put set, exclusive dash window both ends, junk-stamp clamp — are settled, do not re-litigate).

## Global Constraints

- Every new/changed syscall lands in all four places: `sys.h` enum, the builtin STRING block in `src/compiler/cc.c` `main()` (string-only change — cc is bootstrap + byte-identity sensitive), the kernel switch in `src/kernel/kernel.ino`, the switch in `host_linux.c`.
- `src/compiler/cc.c`, `src/basic/*`, `src/userland/*` stay compilable by the committed board cc (bootstrap); no-`-O` output byte-identical (`tools/check_ref.py` → `different: 0`).
- No absolute addresses; userland never includes kernel headers (bounds like `MTIME_UNKNOWN` are defined locally with a comment).
- `fs_time_cb` only reads `clock_now()`/`clock_valid()` — no task-switch point, no allocation, no PSRAM touch (it runs inside SDFS write paths).
- Constants, verbatim from the spec: `MTIME_UNKNOWN = 315532800` (1980-01-01 UTC), `MTIME_MAX = 2147483647`; dash window is `mtime <= MTIME_UNKNOWN || mtime >= MTIME_MAX` (both bounds exclusive from display).
- `ls` per-file line: `%04d-%02d-%02d %02d:%02d  %8d  %s` from `tzlocal(mtime)` civil fields formatted as-if-UTC; `----------` + two spaces outside the window; `<dir>` lines and the `%d files, %d bytes` trailer byte-identical to today.
- QEMU gates must not depend on ambient `TZ`: `check_toolchain.py` already strips it at its spawn; `check_sh.py`'s `run()` gets the same strip (Task 3).
- Gates from AGENTS.md triage: compiler/userland change → `check_ref` + affected `check_*` + `make`; kernel change → the Challenger compile gate (`FQBN=rp2040:rp2040:challenger_2350_wifi6_ble5:flash=8388608_7340032,espwifitype=esp_hosted`, `--library third_party/ESPHost`, `--build-property "compiler.cpp.extra_flags=-I$PWD"`), exit 0 + sizes; board work only in Task 5.
- Board safety: one holder on the port (`T2DOS_PORT=/dev/serial/by-id/usb-iLabs_Challenger_2350_WiFi_BLE_B63788AFE9874C9D-if00`), never kill the user's `screen`, hub cycle only `uhubctl -l 3-1.4 -p 4 -a cycle -d 3`.

## Review Focus

(Classes no single task's tests fully pin; each line is pinned by the named task's named step.)

1. Unsynced or pre-1980 clock must produce the sentinel, never a wrapped DOS year — Task 2 Step (callback guard) + Task 5 unsynced-window leg.
2. Pre-Round-B junk stamps on existing card files (~2097 values) render `----`, not dates — Task 3 staged past-ceiling leg + Task 5 old-file leg.
3. Per-file DST honesty: a July mtime listed in November shows July's local calendar (+02:00), not today's offset — Task 1 `tzlocal` legs + Task 3 staged pair.
4. Stale card binaries that pass old 72-byte `dirent_t` buffers are corrupted by the widened struct — Task 5 re-put step derives its list from `grep -l 'readdir\|dirent_t' src/*/*.c` (expect `{ls,rcp,sh,basic}`), all re-`put`.
5. SDFS's DOS-seconds packing drifts up to ~±1 min unless the stamp is minute-truncated — Task 2 guard code shape + Task 5 minute-exact leg.
6. Byte-exact goldens outside the feature (`date -u`, `ls` dir lines/summary, other `check_sh` cases) must not shift — every task's `make check` + `check_ref` run.
